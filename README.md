# Fullstack Developer - Golang & React

## Deskripsi Showcase

Project ini merupakan aplikasi web fullstack yang dibuat menggunakan
Golang sebagai backend dan React sebagai frontend.

## Teknologi
- Golang
- Gin
- MySQL
- GORM
- JWT
- React
- TypeScript
- Axios

## Fitur
- Register
- Login
- Authentication JWT
- Dashboard
- CRUD User

## Showcase
Project ini dibuat sebagai hasil pembelajaran kelas
Fullstack Developer dengan Golang dan React di SantriKoding.
